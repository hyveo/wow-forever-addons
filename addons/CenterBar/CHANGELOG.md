# 변경 내역

## 1.2.0 — 2026-11-19

- 예전 센터바의 설정을 다시 넣음: 배율(70~200%)·투명도(0~100%)·이동간격(2~20) 슬라이더, 전투 시/대상 선택 시/마우스오버 시 투명도 복구, 탈것 탑승 시 숨김(일반 탈것 포함), 빈 버튼 항상 표시, 툴팁 숨김
- 슬롯마다 쓰는 액션바 페이지(버튼 1~12, 추가 버튼 13~18)를 직접 고를 수 있음
- 격자의 CENTER 칸을 끌어 전체를 위아래로 옮기기, 가로·세로 위치 미세 조정 버튼
- 빈 버튼은 기본으로 안 보이게 (화면을 덜 가림), 빈 칸 테두리를 얇게
- "보이기(항상/전투 중/마우스)" 선택은 투명도 + 복구 조건으로 바뀜

## 1.1.3 — 2026-11-19

- 설정 창을 열면 화면 전체 격자가 나오고, 번호 칸을 끌어 버튼을 하나씩 옮길 수 있음 (대칭 이동 포함)

## 1.1.2 — 2026-11-19

- 기술이 들어 있는 칸은 테두리 없이 아이콘만 보이게 (테두리는 빈 칸에만)

## 1.1.1 — 2026-11-19

- 재사용 대기시간 오류(`SetCooldown ... Secret values`) 수정: 버튼을 게임 기본 틀 대신 직접 그리도록 바꿈
- 배치를 예전 센터바와 같은 자리로: 기본 / 둥글게 / 세로 3줄 1~3 중 선택, 화면 한가운데 기준
- 칸 테두리(격자)를 직접 그려서 항상 보이게
- "버튼 간격·캐릭터와 거리" 설정은 "퍼짐" 하나로 합침

## 1.1.0 — 2026-11-19

- 버튼에 기술을 끌어다 놓으면 "기능이 차단되었습니다"가 뜨던 문제 수정
- 예전 센터바처럼 빈 칸 테두리(격자)와 퀵슬롯 모양 테두리, 아이콘이 칸을 꽉 채우게
- 모양 고르기: 둥글게(기본) / 반듯하게
- 슬롯 1~3 추가 (`/cb 1`~`/cb 3`, 단축키 "센터바 다음 슬롯"). 슬롯 1은 예전 센터바와 같은 칸이라 예전에 넣은 기술이 그대로 보임
- 버튼 번호와 자리를 예전 센터바와 같게 맞춤
- 특성별 페이지 설정은 슬롯으로 바뀜

## 1.0.1 — 2026-11-19

- 설정 창 명령어를 `/cb`로 변경 (`/centerbar`, `/센터바`도 그대로 동작, `/cbar`는 제거)

## 1.0.0 — 2026-11-19

- 첫 버전 (처음부터 새로 만든 센터바)
- 버튼 최대 18개, 표시 개수 6/12/18
- 특성별 액션바 페이지, 13~18번 추가 페이지
- 보이기 방식(항상/전투 중/마우스 올렸을 때), 크기·투명도·간격·거리, 위치 잠금, 툴팁 끄기
- 단축키 18개, 설정 창(`/센터바`)
- hyveo 애드온 센터용 공개 API(`CenterBar`)
