# 변경 내역

## 1.3.3 — 2026-11-19

- 기본 배치를 곡선(예전 센터바의 "기본형식")으로 변경. "세로 3줄"을 그대로 쓰던 경우 곡선으로 바뀜
- 배치 이름을 예전 센터바와 같게: 곡선 (기본형식), 3x3(1)~(3)

## 1.3.2 — 2026-11-19

- 설정에 "채팅창 메시지 숨김" 추가 (슬롯 변경 등 안내 문구를 끔)
- 설정 창의 화면 전체 격자를 예전 센터바와 같은 방식(화면에 바로 붙인 판)으로 다시 그림

## 1.3.1 — 2026-11-19

- 미니맵 버튼 추가: 왼쪽 클릭 = 설정 창, 오른쪽 클릭 = 다음 슬롯, 드래그로 미니맵 둘레를 따라 옮기기 (설정에서 숨길 수 있음)

## 1.3.0 — 2026-11-19

- 슬롯 내용이 다른 액션바·다른 슬롯과 섞이던 문제 해결: 버튼에 넣은 기술을 게임 액션바 칸이 아니라 센터바가 직접 저장 (캐릭터별)
- 슬롯 5개 (`/cb 1`~`/cb 5`), 슬롯끼리 완전히 따로
- "슬롯 페이지 / 추가 버튼 페이지" 설정 제거
- 예전에 넣어 둔 기술(예전 센터바의 2페이지 + 10페이지 등)은 처음 접속할 때 한 번 자동으로 가져옴
- 버튼에는 주문, 아이템, 매크로를 넣을 수 있음

## 1.2.4 — 2026-11-19

- 빈 칸 테두리를 예전 센터바와 같은 옅은 퀵슬롯 테두리로

## 1.2.3 — 2026-11-19

- 설정 창의 격자가 가운데 선만 보이던 문제 수정: 예전 센터바처럼 화면 끝에서 끝까지, 화면 기준으로 그림

## 1.2.2 — 2026-11-19

- 기술이 들어 있는 칸의 테두리가 남던 문제 수정 (매번 다시 숨기도록)

## 1.2.1 — 2026-11-19

- 접속 직후 `attempt to index local 'xs'` 오류 수정 (버튼 자리를 준비하기 전에 배치를 계산하던 문제)

## 1.2.0 — 2026-11-19

- 예전 센터바의 설정을 다시 넣음: 배율(70~200%)·투명도(0~100%)·이동간격(2~20) 슬라이더, 전투 시/대상 선택 시/마우스오버 시 투명도 복구, 탈것 탑승 시 숨김(일반 탈것 포함), 빈 버튼 항상 표시, 툴팁 숨김
- 슬롯마다 쓰는 액션바 페이지(버튼 1~12, 추가 버튼 13~18)를 직접 고를 수 있음
- 격자의 CENTER 칸을 끌어 전체를 위아래로 옮기기, 가로·세로 위치 미세 조정 버튼
- 빈 버튼은 기본으로 안 보이게 (화면을 덜 가림), 빈 칸 테두리를 얇게
- "보이기(항상/전투 중/마우스)" 선택은 투명도 + 복구 조건으로 바뀜

## 1.1.3 — 2026-11-19

- 설정 창을 열면 화면 전체 격자가 나오고, 번호 칸을 끌어 버튼을 하나씩 옮길 수 있음 (대칭 이동 포함)

## 1.1.2 — 2026-11-19

- 기술이 들어 있는 칸은 테두리 없이 아이콘만 보이게 (테두리는 빈 칸에만)

## 1.1.1 — 2026-11-19

- 재사용 대기시간 오류(`SetCooldown ... Secret values`) 수정: 버튼을 게임 기본 틀 대신 직접 그리도록 바꿈
- 배치를 예전 센터바와 같은 자리로: 기본 / 둥글게 / 세로 3줄 1~3 중 선택, 화면 한가운데 기준
- 칸 테두리(격자)를 직접 그려서 항상 보이게
- "버튼 간격·캐릭터와 거리" 설정은 "퍼짐" 하나로 합침

## 1.1.0 — 2026-11-19

- 버튼에 기술을 끌어다 놓으면 "기능이 차단되었습니다"가 뜨던 문제 수정
- 예전 센터바처럼 빈 칸 테두리(격자)와 퀵슬롯 모양 테두리, 아이콘이 칸을 꽉 채우게
- 모양 고르기: 둥글게(기본) / 반듯하게
- 슬롯 1~3 추가 (`/cb 1`~`/cb 3`, 단축키 "센터바 다음 슬롯"). 슬롯 1은 예전 센터바와 같은 칸이라 예전에 넣은 기술이 그대로 보임
- 버튼 번호와 자리를 예전 센터바와 같게 맞춤
- 특성별 페이지 설정은 슬롯으로 바뀜

## 1.0.1 — 2026-11-19
