# Changelog · 변경 내역

Each version lists English first, then Korean. 버전마다 영어를 먼저, 한국어를 그다음에 적습니다.

## 0.2.0 — 2026-11-19

**English**

- Added a minimap button: click to open the addon center and jump to each addon's window from there (drag to move, `/hv minimap` to hide)

**한국어**

- 미니맵 버튼 추가: 클릭하면 애드온 센터가 열리고, 거기서 각 애드온 창으로 이동 (드래그로 위치 이동, `/hv minimap`으로 숨기기)

## 0.1.1 — 2026-11-19

- 센터바 원래 명령어 표시를 `/cb`로 변경
- 아이콘을 hyveo 로고(F안)로 변경

## 0.1.0 — 2026-11-19

- 첫 버전
- 레벨페이스·센터바 상태/버전 표시, 켜기/끄기, 창 열기
- 빠른 설정 (레벨페이스 정보 바 보이기·잠금, 센터바 전투 중에만·마우스 올렸을 때만 보이기)
- `/hv lp`, `/hv cb`, `/hv help` 명령어로 각 애드온 바로 열기
- 여는 곳: `/hv`(또는 `/hyveo`) 명령어, 미니맵 옆 애드온 메뉴, 게임 설정 > 애드온
- 설치 안 된 애드온 받는 곳 / 버그 제보 주소 복사
