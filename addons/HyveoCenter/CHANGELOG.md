# Changelog · 변경 내역

Each version lists English first, then Korean. 버전마다 영어를 먼저, 한국어를 그다음에 적습니다.

## 1.1.0 — 2026-11-25

**English**

- Error log: if one of hyveo's addons hits an error, it is quietly written down instead of being lost. Open it with `/hv errors`, copy it, and post it in a GitHub issue or a CurseForge comment. It holds no character, realm or account names
- The addon center window has an "Error log" button
- The log covers CenterBar, LevelPace and hyveo Addon Center together, whichever of them you open it from

**한국어**

- 오류 기록: hyveo 애드온에서 오류가 나면 사라지지 않고 조용히 적어 둬요. `/hv 오류`(또는 `/hv errors`)로 열어서 복사한 뒤 GitHub 이슈나 CurseForge 댓글에 올려 주세요. 캐릭터·서버·계정 이름은 들어가지 않아요
- 애드온 센터 창에 "오류 기록" 버튼이 생겼어요
- 센터바, 레벨페이스, hyveo 애드온 센터의 오류를 한곳에 모아 보여 줘요. 어느 애드온에서 열어도 같은 기록이에요

## 1.0.0 — 2026-11-21

**English**

- First stable release
- Now in 10 languages: English, 한국어, Deutsch, Español (América Latina), Español (España), Français, Português, Русский, 简体中文, 繁體中文
- New language picker on the left side of the center. It sets the language for all hyveo addons (CenterBar and LevelPace follow it). Default is "Auto" (game language); changes apply after reloading the UI
- Minimap button: click to open the center, drag to move it around the minimap, `/hv minimap` to hide it
- Minimap button tooltip, addon list title and description are translated too

**한국어**

- 첫 정식 버전
- 10개 언어 지원: English, 한국어, Deutsch, Español (América Latina), Español (España), Français, Português, Русский, 简体中文, 繁體中文
- 센터 왼쪽에 언어 선택 추가. 여기서 고른 언어를 모든 hyveo 애드온(센터바, 레벨페이스)이 따라가요. 기본값은 "자동"(게임 언어)이고, UI를 다시 불러오면 적용돼요
- 미니맵 버튼: 클릭하면 센터가 열리고, 드래그로 미니맵 둘레를 따라 옮기고, `/hv minimap`으로 숨겨요
- 미니맵 버튼 툴팁, 애드온 목록의 이름·설명도 언어별로 나와요

## 0.1.0 — 2026-11-19

- 첫 버전
- 레벨페이스·센터바 상태/버전 표시, 켜기/끄기, 창 열기
- 빠른 설정 (레벨페이스 정보 바 보이기·잠금, 센터바 전투 중에만·마우스 올렸을 때만 보이기)
- `/hv lp`, `/hv cb`, `/hv help` 명령어로 각 애드온 바로 열기
- 여는 곳: `/hv`(또는 `/hyveo`) 명령어, 미니맵 옆 애드온 메뉴, 게임 설정 > 애드온
- 설치 안 된 애드온 받는 곳 / 버그 제보 주소 복사
